Termio

BETA

A dedicated browser terminal powered by OpenRouter hosted Shell.

  • Termio runs real shell commands inside a hosted Linux environment provided by OpenRouter.
  • You bring your own OpenRouter API key. Termio never bundles or proxies one.
  • Shell is a beta feature. It runs in a limited, isolated, hosted sandbox.
  • That environment is not your own computer. Files and state are container-scoped.
  • Using Shell and the selected model can consume OpenRouter credits and may incur charges.
  • Stored sessions and container data may be limited or temporary.

By continuing you acknowledge the beta limits described above.
