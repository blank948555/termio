Policy Compliance: Misuse of shell commands or violation of OpenRouter terms of service may result in restriction or ban of your API key by OpenRouter.

Maintainer Non-Liability: Termio maintainers are non-liable for container session behavior, data loss, or account restrictions resulting from misuse.

Network Access

Choose whether the hosted shell sandbox may reach the internet.

Network Access OFF — Outbound shell networking disabled

When enabled, commands you run inside the hosted Linux sandbox can connect to a small approved allowlist of domains (such as api.github.com and pypi.org). When disabled, the container has no outbound internet access at all. You can change this later in Settings, and view the full domain list there.

Alpha Network Access is in an alpha stage and not fully tested. It may behave unexpectedly, and the allowlist may change as the feature stabilizes.

Privacy & Data

How your data moves when using Termio.

  • Prompts & Commands: The commands you enter are sent to OpenRouter so it can process your model requests. The selected model and provider handle request content through OpenRouter's infrastructure.
  • Hosted Shell: Shell and tool requests run on OpenRouter's hosted infrastructure in a sandboxed Linux container, not on your device.
  • Network Access: When Network Access is enabled, requests from the hosted shell may reach the allowed external domains listed in Settings. When it is off, the container has no outbound internet access. This is an alpha-stage feature and is not fully tested.
  • Local Storage: Termio preferences, saved sessions, and history can remain on your device in IndexedDB. They are not required for the terminal to function and can be cleared anytime in Settings.
  • API Keys: Your OpenRouter API key is stored only in this browser and is sent only where required to authenticate requests with the OpenRouter API. It is never logged, displayed publicly, added to URLs, or sent anywhere else.
